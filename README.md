## 🚀 Projects & Real-World Exploration

I particularly enjoy projects that start with an actual problem rather than just a technical exercise.

### 🚕 Mobility in Sousse — Research & Data Exploration

**Understanding urban mobility through data.**

One of my ongoing research interests focuses on shared-taxi transportation (Louage) in Sousse, Tunisia.

The project explores:
- Understanding shared-taxi transportation patterns.
- Investigating mobility demand and passenger flows.
- Exploring how data analysis can reveal useful insights.
- Considering Machine Learning for future demand prediction.

**The bigger idea:** What if we could use data and intelligent systems to better understand local transportation challenges?
